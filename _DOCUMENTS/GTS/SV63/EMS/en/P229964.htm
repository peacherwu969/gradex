Note:

Ask and check the driver's driving habits. The accelerator pedal and brake pedal cannot be depressed at the same time.

1      Component Check: Accelerator Pedal Sensor
1.1   Signal voltage detection

1.1.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

1.1.2    Plug the ECU vehicle harness connector K

1.1.3    Plug the accelerator pedal sensor harness connector

1.1.4    Place the ignition switch in ON position

1.1.5    Read the signal voltage value of accelerator pedal sensor 1 and accelerator pedal sensor 2 and calculated opening with a scan tool

 

Note:

If the relevant signal value cannot be read from the scan tool, use the jumper box to directly measure the voltage value of relevant pin of the accelerator pedal sensor.

 

Accelerator pedal sensor 1

Jumper box

ECU pin K32 to passenger compartment ground

Normal value: 0.7~0.8V (accelerator pedal fully released)

Normal value: 4.0~4.2V (accelerator pedal fully depressed)

Accelerator pedal sensor 2

Jumper box

ECU pin K33 to passenger compartment ground

Normal value: 0.3~0.4 V (accelerator pedal fully released)

Normal value: 2.0~2.1 V (accelerator pedal fully depressed)

 

Possible causes:

Accelerator pedal sensor or harness failure

 
2      Component Check: Brake Switch
2.1   Resistance detection

2.1.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.1.2    Pull out the brake switch harness connector

2.1.3    Directly measure the resistance between brake switch pins

Main brake switch /

Pin 3 to pin 4

Normal value: ≥ 1MΩ / Release the brake pedal

Normal value: ~ 0Ω / Depress the brake pedal

Auxiliary brake switch /

Pin 1 to pin 2

Normal value: ~ 0Ω / Release the brake pedal

Normal value: ≥ 1MΩ / Depress the brake pedal

 

Possible causes:

Brake switch or harness failure (refer to 7.3.7          DTCs---Brake Switch on Page 164 for further troubleshooting)

 
2.2   Signal voltage detection

2.2.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.2.2    Plug the ECU vehicle harness connector K

2.2.3    Plug the brake switch harness connector

2.2.4    Place the ignition switch in ON position

2.2.5    Read the data flow with the scan tool: main brake switch and auxiliary brake switch

 

Data flow:

Main brake switch

 

Normal value: Depress/Depress the brake pedal

Normal value: Release/Release the brake pedal

Auxiliary brake switch

 

Normal value: Depress/Depress the brake pedal

Normal value: Release/Release the brake pedal

 

Note:

If the relevant signal value cannot be read from the scan tool, use the jumper box to directly measure the voltage value of relevant pin of the brake switch.

 

Main brake switch

 

Jumper box

ECU pin K54 to passenger compartment ground

Normal value: ~ 0V / Release the brake pedal

Normal value: 10~14V / Depress the brake pedal

 

 

Auxiliary brake switch

 

Jumper box

ECU pin K12 to passenger compartment ground

Normal value: 10~14V / Release the brake pedal

Normal value: ~ 0V / Depress the brake pedal

 

Possible causes:

Brake switch or harness failure (refer to 7.3.7          DTCs---Brake Switch on Page 164 for further troubleshooting)
