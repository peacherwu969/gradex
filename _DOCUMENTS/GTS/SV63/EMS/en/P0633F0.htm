Possible Failures

1.   System indicator/MIL stays on

2.   Unable to start the engine

Pre-check

1.   Battery fully charged

2.   Vehicle fuses are OK

3.   All connectors are OK, and there is no loose connector or pin corrosion

Inspection Tools

1.   Scan tool

1      Immobilizer Matching
1.1   Connect the scan tool to OBD diagnosis connector
1.2   Place the ignition switch in ON position
1.3   Match the immobilizer system with the scan tool
1.4   Place the ignition switch in OFF position, and wait for at least 60 seconds

Possible causes:

Immobilizer system unmatched

Immobilizer system failure

 

 

End of test
