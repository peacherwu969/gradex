Possible Failures

1.   System indicator/MIL stays on

2.   Low engine power

3.   Increased engine idle speed

4.   High fuel consumption

5.   Oil dilution

6.   Engine smoking

Pre-check

1.   Battery fully charged

2.   Vehicle fuses are OK

3.   All connectors are OK, and there is no loose connector or pin corrosion

Inspection Tools

1.   Multimeter, scan tool

2.   Jumper box

1      Power Supply Check
1.1   Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)
1.2   Pull out the DPF upstream temperature sensor harness connector
1.3   Place the ignition switch in ON position
1.4   Measure the voltage of DPF upstream temperature sensor harness connector pin 2 to the passenger compartment ground

 

Normal value: 4.9 ~ 5.1V

 

Possible causes:

Damaged harness (make further troubleshooting through Step 2 "Harness Inspection")

Damaged connector (visually check if the connector is intact)

 
2      Harness Inspection
2.1   Open circuit detection

2.1.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.1.2    Pull out the ECU vehicle harness connector K

2.1.3    Pull out the DPF upstream temperature sensor harness connector

2.1.4    Measure the resistance between the DPF upstream temperature sensor harness connector pin and the ECU harness connector pin

 

Normal value: ~ 0Ω / Pin 1 to ECU pin K74

Normal value: ~ 0Ω / Pin 2 to ECU pin K75

 

Possible causes:

Harness open-circuited

Damaged connector (visually check if the connector is intact)

 
2.2   Short-to-ground detection

2.2.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.2.2    Pull out the ECU vehicle harness connector K

2.2.3    Pull out the DPF upstream temperature sensor harness connector

2.2.4    Measure the resistance between the DPF upstream temperature sensor harness connector pin and the passenger compartment ground

 

Normal value: ≥ 1MΩ / Pin 1 to passenger compartment ground

Normal value: ≥ 1MΩ / Pin 2 to passenger compartment ground

 

Possible causes:

Harness short to ground

Damaged connector (visually check if the connector is intact)

 
2.3   Harness internal short circuit detection

2.3.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.3.2    Pull out the ECU vehicle harness connector K

2.3.3    Pull out the DPF upstream temperature sensor harness connector

2.3.4    Measure the resistance between pin 1 and pin 2 of the DPF upstream temperature sensor harness connector

 

Normal value: ≥ 1MΩ

 

Possible causes:

Harness short to battery

Damaged connector (visually check if the connector is intact)

 
3      Component Check
3.1   Resistance detection

3.1.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

3.1.2    Pull out the DPF upstream temperature sensor harness connector

3.1.3    Measure the resistance between pin 1 and pin 2 of the DPF upstream temperature sensor

 

Possible causes:

Damaged DPF upstream temperature sensor

 
3.2   Signal voltage detection

3.2.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

3.2.2    Plug the DPF upstream temperature sensor harness connector

3.2.3    Plug the ECU vehicle harness connector K

3.2.4    Read the data flow with the scan tool: DPF upstream temperature

 

Data flow

DPF upstream temperature, DPF upstream temperature signal voltage

Note:

If the relevant signal value cannot be read from the scan tool, use the jumper box to directly measure the voltage value of relevant pin of the DPF upstream temperature sensor.

 

DPF upstream temperature sensor signal voltage

Jumper box

ECU pin K75 to passenger compartment ground

 

Possible causes:

Damaged DPF upstream temperature sensor
