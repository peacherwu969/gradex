2.   Vehicle fuses are OK

1      NOx Sensor Physical Inspection
1.1   Visually check if NOx sensor is properly installed. Check if NOx sensor is installed in correct position; and if it is damaged due to impact.

Possible causes:

Incorrect installation (re-install)

Damaged NOx sensor (replace NOx sensor)

Note:

The downstream NOx sensor is used for OBD monitoring and will report an error if the wrong data is used. Therefore, the correct data is the premise of this test.

 
1      Power Supply Check
1.1   Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)
1.2   Pull out the NOx sensor harness connector
1.3   Place the ignition switch in ON position
1.4   Measure the voltage of NOx sensor harness connector pin 5 to the passenger compartment ground

 

Normal value: 10~14 V

Possible causes:

Harness failure (make further troubleshooting through Step 3 "Harness Inspection")

 
2      Harness Inspection
2.1   Open circuit check

2.1.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.1.2    Pull out the ECU vehicle harness connector K

2.1.3    Pull out the NOx sensor harness connector

2.1.4    Measure the resistance between NOx sensor harness connector pin and ECU vehicle harness pin K

 

Normal value: ~0Ω / Pin 2 to ECU pin K81

Normal value: ~0Ω / Pin 3 to ECU pin K80

Possible causes:

Harness open-circuited

Damaged harness connector (visual check)

 
2.2   Short-to-ground check

2.2.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.2.2    Pull out the ECU vehicle harness connector K

2.2.3    Pull out the NOx sensor harness connector

2.2.4    Measure the resistance between NOx sensor harness connector pin and the passenger compartment ground

 

Normal value: ≥ 1MΩ / Pin 2 to passenger compartment ground

Normal value: ≥ 1MΩ / Pin 3 to passenger compartment ground

Possible causes:

Harness short to ground

Damaged connector (visual check)

 
2.3   Harness internal short circuit detection

2.3.1    Place the ignition switch in OFF position (if the last status of the ignition switch is ON, then after placing it in OFF position, please wait at least 2 minutes before proceeding to avoid hot plugging)

2.3.2    Pull out the ECU vehicle harness connector K

2.3.3    Pull out the NOx sensor harness connector

2.3.4    Measure the resistance between the NOx sensor harness connector pin and all other pins of the connector

 

Normal value: ≥ 1 MΩ / Pin 1 to all other pins

Normal value: ≥ 1 MΩ / Pin 2 to all other pins

Normal value: ≥ 1 MΩ / Pin 3 to all other pins

Normal value: ≥ 1 MΩ / Pin 4 to all other pins

Normal value: ≥ 1 MΩ / Pin 5 to all other pins

Possible causes:

Harness internal short circuit

Damaged connector (visually check if the connector is intact)

 
3      Component Check

If above checks do not eliminate the failure, it indicates that the NOx sensor is faulty. Replace NOx sensor or contact NOx sensor manufacturer to resolve this issue.

Possible causes:

NOx sensor failure

 

 

End of test
