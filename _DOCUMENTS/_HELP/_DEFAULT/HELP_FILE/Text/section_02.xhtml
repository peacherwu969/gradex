诊断功能概况

诊断程序主界面是框架式显示，左边是功能选择区，依次为车辆信息、故障码、数据流、执行器测试、配置、特殊功能、刷写、测试报告,右边是内容显示区

点击左侧菜单选择不同的诊断功能。


车辆信息功能介绍

诊断程序的主界面进入后就默认进入车辆信息功能。画面右边显示的是车辆的基本信息。靠上的部分显示制造商、车型以及VIN码。在画面中间部分显示的是该车的车辆信息，例如品牌、车身长度、方向盘位置、产地、动力类型、生产年份等信息。


在底部有2个按钮，默认选择左边的车辆信息按钮。而点击右边的ECU信息按钮，系统自动读取各个ECU的版本信息并显示各ECU的零部件的号码，包括硬件号，软件号，VIN码等。


故障码功能介绍

选择故障码菜单后，系统默认自动读取故障码。点击界面底部功能按钮可以实现全部ECU的故障码清除及刷新故障码。


功能从左往右依次为：
  • 1. 清除全部ECU故障码
  • 2. 清除全部ECU故障码后再次刷新当前所有ECU故障码状态
  • 3. 刷新全部ECU故障码状态
  • 4. 取消

读故障码界面中每个ECU名称的最右侧会显示当前ECU的故障码数量


点击故障码数量右侧的圆形按钮会显示当前ECU的故障码清除及刷新故障码功能。


当故障码有冻结帧时会显示冻结帧的图标（照相机图标）


点击（照相机图标）右侧的圆形按钮后会显示该故障码的冻结帧功能，点击后即显示冻结帧数据。


点击冻结帧数据，读取该故障码的冻结帧。


数据流功能介绍

数据流是显示ECU当前的状态值，比如测试时的发动机转速，电池电压、水温以及车窗车门开关的状态。是维修人员进行车辆诊断及故障判断的重要依据。通过读取当前状态值，维修人员判断车辆的故障。

点击左侧读数据流按钮，右侧该车包含的ECU，点击ECU菜单会显示该ECU包含的数据流项目。选择项目后点击开始监测，诊断仪就会获取所选数据项的信息。

数据流选择界面下方的功能按钮依次为：

  • 1. 数据监控
  • 2. 监控数据回放
  • 3. 开始监控。

数据流项选择可以使用搜索功能来实现快速定位需要选择的数据流项。如图：


数据流监控时可以选择最多8条数据流来进行动态波形图显示，所显示的数据流波形图为开始监控时最先选择的前8条，并且分别以不同颜色来表示。

数据流显示界面的下方有3个按钮，从左往右依次为：

  • 1. 开始记录按钮
  • 2. 停止记录按钮
  • 3. 冻结画面。

1. 开始记录按钮：点击记录按钮后，会让用户输入记录数据名称，点击确认后就开始记录数据。

2. 停止记录按钮：停止记录按钮即停止记录当前数据。

3. 冻结画面：冻结按钮将会让画面暂停，再点击该按钮，画面将继续显示。

执行器测试

执行器测试可以用于对车辆进行一系列动作测试，从而检测相关部件是否可以正常工作。

点击左侧动作测试按钮，展开右侧的ECU菜单选择要进行测试的项目。点击右边的箭头。


如图：对LED灯打开/关闭的测试





配置功能介绍

点击左侧配置按钮，展开右侧的ECU菜单选择要进行配置的项目。点击右边的箭头进入到具体功能

注意：ECU配置功能是对ECU进行状态修改，写入VIN码、最大钥匙数，写入安装日期等有永久影响的操作。如果操作不当会对车辆造成不可预见的后果。所以在执行时候请遵循安全指导或请有资质的人员进行操作。该功能需要安全访问。


例如：写车辆识别号，请按照实际车辆信息写入VIN码，注意：要正确写入VIN码， 否则软件会提示错误信息。



特殊功能介绍

特殊功能是一种集成于电控单元与电控单元或电控单元与传感器之间的配置及学习过程，主要用于防盗配置的相关功能，传感器的校验与学习等。


例如：删除所有钥匙，请按照流程的提示进行操作。





刷写功能介绍

ECU刷新是指改写ECU内部程序，通过此方法可以将供油及点火的在原厂数据基础上进行精细调整，优化参数以达到增加输出马力、提升扭矩或降低油耗的目的。

本功能包含ECU（本地）刷写，点击ECU刷写右边的箭头进行刷写。


测试报告功能介绍

测试报告将汇总用户之前做过的所有操作以及操作的结果。可以使用打印功能打印出结果。
