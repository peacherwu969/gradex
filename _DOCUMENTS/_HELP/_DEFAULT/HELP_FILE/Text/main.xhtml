诊断仪简介

上汽大通车辆诊断仪是一款用于检测车辆故障，获取车辆状态，配置信息，控制器测试，控制器刷新的工具。是车辆生产厂家、4S店必备的车辆诊断维修工具。目前市场上比较常见的诊断仪形式分为手持式设备和PC设备。而PC设备以其高度的灵活性，可扩展性以及友好的用户界面受到消费者的青睐。
车辆诊断仪的功能主要包括读取清除故障码、获取车辆的当前状态信息、读取和修改车辆的配置信息、对车辆进行功能性操作（包括输入输出控制，配钥匙，换ECU后的配置）以及刷写ECU等高级功能。

安全指导

在使用诊断仪测试车辆或其他部件时，请遵循安全指导和危险警告。
