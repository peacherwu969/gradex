The Splash Screen

Diagnostic instrument startup will display a splash screen, then the user login interface will pop up, enter the user name and password, you can access the software.
User name and password are managed by the SAIC MAXUS, If you have questions, please contact us.




ToolBar

Toolbar at the top of interface.


From left to right:
  • VCI Settings: Choose VCI to connect vehicle
  • Setting: Language and units
  • Copy Screen: Screenshot, print screen or content
  • About: Version, license information and help document
  • Exit: Exit application or restart SAIC GRADE-X

Status Bar

Status bar at the bottom of the interface.
From left to right:
  • Version: Current version for SAIC GRADE-X
  • User: Current user for SAIC GRADE-X
  • VIN: VIN of the current vehicle

Model Selection




Click the appropriate model icon to enter Auto Scan or manually ECU selection interface, then begin diagnosis.
