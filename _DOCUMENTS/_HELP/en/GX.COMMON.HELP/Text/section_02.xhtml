Diagnosis Features

Menu is on left side and content is on right side.

Menu include Identification, DTC, Data List, Actuator Test, ECU configuration, Special Functions, Reflash, Test Report.

Choose each menu to select different diagnostic functions.

In Content area you can click buttons to display the appropriate diagnostic items and diagnostic results.


Vehicle Information

The right of the screen shows the basic information of the vehicle. Against the upper part of the display manufacturer, model and VIN number. In the middle part of the screen shows year of manufacture and other information.


There are two buttons on bottom. The left one is vehicle information as default. The right one is ECUs information, include version, part number, VIN code.


DTC

Click on the left button reading Clear DTC, the system automatically reads fault codes. Click the bottom of the screen function button can achieve all of the ECU fault codes Clear fault codes and refresh. Functions from left to right as follows:
1. Clear all ECU fault codes
2. Read DTC of all ECUs after clear DTC of all ECUs
3. Refresh all ECU DTC status
4. Cancel


Click on right top conor button can choose icon or text status


Choose icon or text:


Definition of icon


Right of each ECU item display the number of the ECU fault codes which exists, clear fault codes and refresh function could click radio button.



It will displayed freeze frame icon(like camera) if a fault code has. Click radio button to show detail.



Click freeze frame data, read freeze frame data of the DTC.


Data List

Data List will read current data stream to show ECU values, such as engine speed, battery voltage, temperature and door window switch status. It can help to check vehicle.

Click the button to the left to read the data stream, the right side of the car containing the ECU, click the ECU menu item the ECU data stream contains display. After selecting the item click Start monitoring, diagnostic will obtain information of the selected data items.

Stream selection function button below the screen as follows: 1. Data Monitoring 2. Monitoring data playback 3. Start monitoring


Search function could quickly locate current data item which customer want. Figure:



Can select up to 8 data stream monitoring for dynamic waveform display, the displayed waveform data flow graph were in different colors to represent.

There are three buttons below on bottom: 1. Start Recording 2.Stop recording 3. Freeze screen

1. Start Recording：First input dataset name, then begin recording

2. Stop Recording：Stop recording data

3. Freeze Screen：Freeze current screen, it will continue when click again

Actuator Test

Actuator test can be used to test the vehicle a series of actions in order to detect whether the associated components can work properly.

Expand ECU menu and choose testing what you want.


Figure: yellow LED lights to turn On/Off test





Configuration

Expand the right side of the ECU menu. Click the arrow on the right to enter into specific functions

NOTICE: ECU configuration is to modify the state, write VIN, set maximum number of keys and so on. If the improper operation of the vehicle will cause unforeseen consequences. So please follow the safety guideline or a qualified person to perform the operation. This function requires secure access.


Example: Write the vehicle identification number, please write the real vehicle information. Notice: It will popup an error message if input a wrong value.



Special Function

Special Function is an integrated process for configuration of ECU and ECU or ECU and sensors, mainly for IMMO configuration, sensor calibration and learning.


Example: remove all keys, please follow the instruction





Reflash

ECU FLASH is rewrite ECU internal procedures, this method enables the fuel supply and ignition make fine adjustments by optimization parameters to achieve increased power, torque or reducing fuel consumption.

The features include ECU (local) flash, click ECU flash to begin flashing.


Test Report

Test Report will summary all operation and results. Also you can print it out by print button.
